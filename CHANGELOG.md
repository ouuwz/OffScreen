# Changelog

## v0.1.0 — initial public test release (planned)

- Android Flutter app with local GGUF inference, nature missions, phone-down timer, local journal, and progress.
- Browser PWA with WebLLM/WebGPU local inference, local journal, progress, and a built-in fallback mission library.
- Streamlit/Ollama desktop prototype retained for comparison and local development.
- GitHub Actions workflows for Android build, CI checks, GitHub Pages deployment, and tagged releases.

This is a planned initial release entry. Do not tag/publish it until CI and real-device/browser tests pass.
